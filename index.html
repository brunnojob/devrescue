A repair kit you can inspect

DevRescue recognizes 20 rule families across Node, TypeScript, Python, Docker, Git, PostgreSQL, tests and networking. Each finding contains the observed evidence, available source location and investigation steps. Unknown signatures stay unknown.

git clone https://github.com/brunnojob/devrescue.git
cd devrescue
node bin/devrescue.js analyze examples/build.log
node bin/devrescue.js doctor .
node bin/devrescue.js fix .

Fix previews are local CLI operations. Only supported deterministic changes can be applied with an explicit fix ID, a backup and a stale-file check. Arbitrary log-derived commands are never executed.

CI summary

- uses: brunnojob/devrescue@main
  if: always()
  with:

Pin the Action to a reviewed commit SHA for production. Preserve the exit code of the original build; a diagnostic report is not a passing build.

Optional Azure history

The repository includes a separate authenticated Node API with PostgreSQL storage. It is not enabled here. Provision a dedicated database and runtime role, configure secrets on the backend and verify TLS. Never add database credentials or the API's administrative token to browser code.
